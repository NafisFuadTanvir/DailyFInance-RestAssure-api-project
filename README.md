
This project is an automated regression test suite for validating the Daily Finance API functionalities such as user management, authentication, and cost tracking.
It uses Rest Assured, TestNG, and Gradle for smooth and scalable API testing.

## project Description
1. Visit the url https://dailyfinance.roadtocareer.net/

2. Create a Postman collection by inspecting the API requests for the following features from the Network tab:
a. Register a new user

b. Login by admin (email: admin@test.com, password: admin123)

c. Get user list

d. search the new user by user id

e. edit the user info (e.g. firstname, phonenumber)

f. Login by any user

g. Get item list

h. Add any item

i. Edit any item name

j. Delete any item from the item list

3. automate the collection using Rest Assured. Rest Assured project must follow the POM architecture
